## 新增需求

### 需求：全局搜索对话框
系统必须提供全局搜索对话框，允许用户通过关键词搜索文章和相册内容。

#### 场景：通过导航栏按钮打开搜索
- **当** 用户点击导航栏的搜索图标按钮
- **那么** 应打开全局搜索对话框
- **并且** 搜索输入框自动获得焦点

#### 场景：通过快捷键打开搜索
- **当** 用户按下 Ctrl+K（Windows/Linux）或 Cmd+K（macOS）
- **那么** 应打开全局搜索对话框
- **并且** 搜索输入框自动获得焦点
- **并且** 如果搜索对话框已打开，则关闭对话框

#### 场景：实时搜索显示结果
- **当** 用户在搜索框输入关键词
- **那么** 系统应在输入停止 300ms 后自动搜索
- **并且** 显示匹配的文章和相册结果
- **并且** 结果按相关性或时间排序

#### 场景：键盘导航搜索结果
- **当** 搜索结果显示时
- **那么** 用户可使用上下箭头键选择结果项
- **并且** 按 Enter 键打开选中的结果
- **并且** 按 Esc 键关闭搜索对话框

#### 场景：搜索结果为空
- **当** 搜索关键词没有匹配结果
- **那么** 显示"未找到相关内容"的提示信息
- **并且** 提供清除搜索或尝试其他关键词的建议

#### 场景：切换搜索类型
- **当** 用户在搜索对话框中选择搜索类型（全部/文章/相册）
- **那么** 系统应只显示对应类型的搜索结果
- **并且** 保持当前输入的关键词

### 需求：博客页面搜索筛选
系统必须在博客页面提供搜索和筛选功能，支持按关键词、分类、标签筛选文章。

#### 场景：通过关键词搜索文章
- **当** 用户在博客页面搜索框输入关键词
- **那么** 系统应搜索文章的标题、摘要和内容
- **并且** 显示匹配的文章列表
- **并且** 显示搜索结果数量

#### 场景：按分类筛选文章
- **当** 用户选择特定分类
- **那么** 只显示该分类下的文章
- **并且** 可以与搜索关键词组合使用

#### 场景：按标签筛选文章
- **当** 用户选择一个或多个标签
- **那么** 只显示包含所选标签的文章
- **并且** 可以与搜索关键词和分类筛选组合使用

#### 场景：清除筛选条件
- **当** 用户点击清除按钮或清空搜索框
- **那么** 所有筛选条件应重置
- **并且** 显示所有已发布的文章
- **并且** URL 查询参数应更新

#### 场景：URL 查询参数同步
- **当** 用户应用搜索或筛选条件
- **那么** URL 应更新包含相应的查询参数（如 ?q=关键词&category=分类&tags=标签1,标签2）
- **并且** 用户刷新页面时应保持筛选状态
- **并且** 用户可以分享筛选后的 URL

### 需求：摄影页面搜索
系统必须在摄影页面提供搜索功能，支持按关键词搜索相册。

#### 场景：搜索相册
- **当** 用户在摄影页面搜索框输入关键词
- **那么** 系统应搜索相册的标题和描述
- **并且** 显示匹配的相册列表
- **并且** 显示搜索结果数量

#### 场景：清除搜索
- **当** 用户清空搜索框或点击清除按钮
- **那么** 显示所有已发布的相册
- **并且** URL 查询参数应更新

### 需求：后端搜索 API
系统必须扩展后端 API 支持全文搜索功能。

#### 场景：搜索文章内容
- **当** API 收到包含搜索关键词的请求
- **那么** 使用 PostgreSQL ILIKE 查询匹配标题、摘要或内容包含关键词的文章
- **并且** 查询应不区分大小写
- **并且** 只返回已发布状态的文章

#### 场景：搜索相册内容
- **当** API 收到包含搜索关键词的请求
- **那么** 使用 PostgreSQL ILIKE 查询匹配标题或描述包含关键词的相册
- **并且** 查询应不区分大小写
- **并且** 只返回已发布状态的相册

#### 场景：搜索结果排序
- **当** 返回搜索结果
- **那么** 默认按发布时间倒序排序
- **并且** 支持按浏览量、点赞数等其他字段排序

#### 场景：搜索性能优化
- **当** 执行搜索查询
- **那么** 应使用数据库索引优化查询性能
- **并且** 搜索结果应支持分页
- **并且** 单次查询不应返回超过 100 条结果
