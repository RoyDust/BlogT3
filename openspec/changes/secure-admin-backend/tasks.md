# 任务清单：后台管理系统安全加固与功能完善

本文档列出了实施后台管理系统安全加固和功能完善的具体任务，按优先级和依赖关系排序。

## 里程碑 1：安全与一致性定稿（P0 - 阻塞上线）

### 阶段 1.1：权限检查基础设施

**任务 1.1.1：创建权限检查工具函数**
- 创建 `src/lib/auth-utils.ts` 文件
- 实现 `requireAuth()` 函数：验证用户已登录
- 实现 `requireAdmin()` 函数：验证管理员权限
- 实现 `requireRole(role)` 函数：验证特定角色
- 添加类型定义和错误处理
- **验证**：编写单元测试验证各种场景

**任务 1.1.2：更新 NextAuth 配置支持角色**
- 修改 `src/server/auth/config.ts`
- 在 JWT 回调中添加 role 字段
- 在 session 回调中添加 role 字段
- 更新 TypeScript 类型定义
- **验证**：登录后检查 session 对象包含 role

**任务 1.1.3：更新中间件保护管理路由**
- 修改 `src/middleware.ts`
- 检查用户是否已登录
- 检查用户角色是否为 ADMIN
- 非管理员返回 403 错误
- **验证**：尝试以非管理员身份访问 `/admin/*` 路由

### 阶段 1.2：注册和上传接口安全

**任务 1.2.1：保护注册接口**
- 修改 `src/app/api/auth/register/route.ts`
- 添加环境变量检查（ALLOW_REGISTRATION）
- 生产环境默认禁止注册
- 修改默认角色为 USER（而非 ADMIN）
- **验证**：在生产模式下尝试注册应失败

**任务 1.2.2：保护上传接口**
- 修改 `src/app/api/upload/route.ts`
- 添加 `requireAdmin()` 权限检查
- 移除 CORS 允许所有来源的配置
- 添加上传日志记录
- **验证**：未登录或非管理员上传应失败

**任务 1.2.3：创建上传日志表**
- 在 Prisma schema 中添加 UploadLog 模型
- 创建数据库迁移
- 运行迁移
- **验证**：检查数据库表已创建

### 阶段 1.3：数据访问层统一

**任务 1.3.1：迁移文章 Server Actions**
- 修改 `src/server/actions/posts.ts`
- 在 createPost 中添加 `requireAdmin()` 检查
- 自动绑定 authorId 为当前用户
- 在 updatePost 中添加权限检查
- 在 deletePost 中添加权限检查
- **验证**：非管理员调用应返回权限错误

**任务 1.3.2：迁移分类 Server Actions**
- 修改 `src/server/actions/categories.ts`
- 在所有写操作中添加 `requireAdmin()` 检查
- 移除客户端直接调用 Supabase 的代码
- **验证**：通过 Server Actions 创建/更新/删除分类

**任务 1.3.3：迁移标签 Server Actions**
- 修改 `src/server/actions/tags.ts`
- 在所有写操作中添加 `requireAdmin()` 检查
- 移除客户端直接调用 Supabase 的代码
- **验证**：通过 Server Actions 创建/更新/删除标签

**任务 1.3.4：迁移相册 Server Actions**
- 修改 `src/server/actions/galleries.ts`
- 在所有写操作中添加 `requireAdmin()` 检查
- 自动绑定 authorId 为当前用户
- **验证**：通过 Server Actions 创建/更新/删除相册

### 阶段 1.4：公开 API 内容过滤

**任务 1.4.1：创建公开查询函数**
- 创建 `src/server/queries/posts.ts`
- 实现 `getPublicPosts()` 函数：只返回 PUBLISHED
- 实现 `getPublicPostBySlug()` 函数：验证状态
- 保留 `getAdminPosts()` 用于后台
- **验证**：公开 API 不返回草稿文章

**任务 1.4.2：更新前台页面使用公开 API**
- 修改 `src/app/(public)/blog/page.tsx`
- 使用 `getPublicPosts()` 替代直接查询
- 修改 `src/app/(public)/post/[slug]/page.tsx`
- 使用 `getPublicPostBySlug()` 替代直接查询
- **验证**：前台不显示草稿文章

**任务 1.4.3：添加草稿预览功能**
- 创建 `src/app/admin/preview/[slug]/page.tsx`
- 需要管理员权限
- 显示草稿内容
- 添加预览标识
- **验证**：管理员可以预览草稿

### 阶段 1.5：客户端代码迁移

**任务 1.5.1：更新分类管理组件**

- **验证**：文章删除功能正常

**任务 1.5.3：更新文章编辑页面**

## 依赖关系

- 阶段 1.1 必须在所有其他阶段之前完成（提供基础设施）
- 阶段 1.2 和 1.3 可以并行进行
- 阶段 1.4 依赖阶段 1.3
- 阶段 1.5 依赖阶段 1.3
- 里程碑 2 依赖里程碑 1 完成
- 里程碑 3 依赖里程碑 2 完成

## 验证策略

每个任务完成后必须进行验证：
1. 功能验证：手动测试功能是否正常
2. 权限验证：测试未授权访问是否被阻止
3. 数据验证：检查数据是否正确保存
4. 回归验证：确保现有功能未被破坏
