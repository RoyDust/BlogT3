# 规范：内容管理

## 新增需求

### 需求：CONTENT-001 - 文章管理支持搜索和筛选

后台文章列表必须支持搜索、筛选和排序功能。

#### 场景：按标题搜索文章

**前置条件**:
- 管理员访问文章列表页面

**操作**:
- 在搜索框输入关键词
- 点击搜索按钮

**预期结果**:
- 返回标题包含关键词的文章
- 支持模糊匹配
- 实时更新列表

#### 场景：按状态筛选文章

**前置条件**:
- 管理员访问文章列表页面

**操作**:
- 选择状态筛选器（草稿/已发布/归档）

**预期结果**:
- 只显示选中状态的文章
- 显示每个状态的文章数量
- 支持多选

#### 场景：按分类筛选文章

**前置条件**:
- 管理员访问文章列表页面

**操作**:
- 选择分类筛选器

**预期结果**:
- 只显示该分类下的文章
- 显示分类名称
- 支持切换分类

### 需求：CONTENT-002 - 文章编辑支持标签选择

文章编辑页面必须提供标签选择功能。

#### 场景：创建文章时选择标签

**前置条件**:
- 管理员在文章编辑页面

**操作**:
- 从标签列表中选择多个标签
- 保存文章

**预期结果**:
- 文章与选中的标签关联
- 标签显示在文章详情中
- 支持多选标签

#### 场景：编辑文章时修改标签

**前置条件**:
- 文章已有关联标签

**操作**:
- 取消选择某些标签
- 添加新标签
- 保存文章

**预期结果**:
- 更新文章的标签关联
- 删除旧的关联
- 添加新的关联
