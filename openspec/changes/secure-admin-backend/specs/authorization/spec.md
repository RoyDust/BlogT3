# 规范：授权系统

## 新增需求

### 需求：AUTHZ-001 - 提供统一的权限检查函数

必须创建统一的权限检查工具函数,用于验证用户身份和角色。

#### 场景：requireAuth 验证用户已登录

**前置条件**:
- 函数在 Server Action 或 API 路由中调用

**操作**:
- 调用 `requireAuth()`

**预期结果**:
- 如果用户已登录,返回用户信息（id, email, name, role）
- 如果用户未登录,抛出错误 "未登录"

#### 场景：requireAdmin 验证管理员权限

**前置条件**:
- 函数在 Server Action 或 API 路由中调用

**操作**:
- 调用 `requireAdmin()`

**预期结果**:
- 如果用户是 ADMIN,返回用户信息
- 如果用户不是 ADMIN,抛出错误 "需要管理员权限"
- 如果用户未登录,抛出错误 "未登录"

#### 场景：requireRole 验证特定角色

**前置条件**:
- 函数在 Server Action 或 API 路由中调用

**操作**:
- 调用 `requireRole('MODERATOR')`

**预期结果**:
- 如果用户角色匹配,返回用户信息
- 如果用户角色不匹配,抛出错误 "权限不足"
- 如果用户未登录,抛出错误 "未登录"

### 需求：AUTHZ-002 - 所有后台写操作必须验证管理员权限

所有创建、更新、删除操作的 Server Actions 必须调用权限检查函数。

#### 场景：创建文章需要管理员权限

**前置条件**:
- 用户调用 `createPost()` Server Action

**操作**:
- 提交文章数据

**预期结果**:
- 如果用户是 ADMIN,创建文章成功
- 如果用户不是 ADMIN,返回错误 "需要管理员权限"
- 如果用户未登录,返回错误 "未登录"

#### 场景：删除分类需要管理员权限

**前置条件**:
- 用户调用 `deleteCategory()` Server Action

**操作**:
- 提交分类 ID

**预期结果**:
- 如果用户是 ADMIN,删除分类成功
- 如果用户不是 ADMIN,返回错误 "需要管理员权限"

### 需求：AUTHZ-003 - 上传接口必须验证管理员权限

图片上传接口必须验证用户是管理员。

#### 场景：管理员可以上传图片

**前置条件**:
- 用户已登录且角色为 ADMIN

**操作**:
- 调用 `/api/upload` 接口上传图片

**预期结果**:
- 上传成功
- 返回图片 URL
- 记录上传日志

#### 场景：非管理员不能上传图片

**前置条件**:
- 用户已登录但角色为 USER

**操作**:
- 调用 `/api/upload` 接口上传图片

**预期结果**:
- 上传失败
- 返回 403 状态码
- 返回错误消息 "需要管理员权限"

#### 场景：未登录用户不能上传图片

**前置条件**:
- 用户未登录

**操作**:
- 调用 `/api/upload` 接口上传图片

**预期结果**:
- 上传失败
- 返回 401 状态码
- 返回错误消息 "未登录"

### 需求：AUTHZ-004 - 中间件保护管理后台路由

Next.js 中间件必须保护所有 `/admin/*` 路由。

#### 场景：已登录管理员可以访问后台

**前置条件**:
- 用户已登录且角色为 ADMIN

**操作**:
- 访问 `/admin/posts` 页面

**预期结果**:
- 页面正常加载
- 显示文章列表

#### 场景：未登录用户重定向到登录页

**前置条件**:
- 用户未登录

**操作**:
- 访问 `/admin/posts` 页面

**预期结果**:
- 重定向到 `/admin/login`
- URL 包含 callbackUrl 参数

#### 场景：非管理员用户不能访问后台

**前置条件**:
- 用户已登录但角色为 USER

**操作**:
- 访问 `/admin/posts` 页面

**预期结果**:
- 返回 403 错误页面
- 显示 "需要管理员权限" 消息
