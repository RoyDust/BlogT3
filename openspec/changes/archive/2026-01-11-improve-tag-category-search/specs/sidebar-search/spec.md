# 规范：侧边栏搜索功能

## 功能 ID
`sidebar-search`

## 目的
提供侧边栏的分类和标签导航功能，允许用户通过点击侧边栏的分类或标签快速筛选文章。

---

## 修改需求

### 需求：侧边栏显示真实分类和标签数据
侧边栏必须从数据库获取并显示真实的分类和标签数据，而不是使用硬编码的 Mock 数据。

#### 场景：显示所有分类
- **当** 用户访问包含侧边栏的页面
- **那么** 侧边栏应显示所有数据库中的分类
- **并且** 每个分类应显示其名称、颜色和文章数量
- **并且** 分类按名称字母顺序排序

#### 场景：显示所有标签
- **当** 用户访问包含侧边栏的页面
- **那么** 侧边栏应显示所有数据库中的标签
- **并且** 每个标签应显示其名称
- **并且** 标签按名称字母顺序排序

#### 场景：动态计算分类文章数量
- **当** 侧边栏加载分类数据
- **那么** 系统应查询每个分类下已发布文章的数量
- **并且** 在分类名称旁边显示文章数量
- **并且** 只统计状态为 PUBLISHED 的文章

#### 场景：数据获取失败的降级处理
- **当** 从数据库获取分类或标签数据失败
- **那么** 侧边栏应显示空列表或默认提示
- **并且** 不应导致页面崩溃或显示错误
- **并且** 应在控制台记录错误信息

---

## 新增需求

### 需求：侧边栏分类链接使用 ID 参数
侧边栏的分类链接必须使用分类 ID 作为 URL 参数，以便与博客搜索组件正确集成。

#### 场景：点击分类链接跳转
- **当** 用户点击侧边栏的某个分类
- **那么** 应跳转到博客页面
- **并且** URL 应包含 `?category={categoryId}` 参数
- **并且** 博客页面应显示该分类下的所有文章

#### 场景：分类链接格式正确
- **给定** 一个分类的 ID 为 "abc-123"
- **当** 渲染该分类的链接
- **那么** 链接的 href 应为 `/blog?category=abc-123`
- **并且** 不应使用 slug 或 name 作为参数值

---

### 需求：侧边栏标签链接使用 ID 参数
侧边栏的标签链接必须使用标签 ID 作为 URL 参数，并使用 `tags` 作为参数名。

#### 场景：点击标签链接跳转
- **当** 用户点击侧边栏的某个标签
- **那么** 应跳转到博客页面
- **并且** URL 应包含 `?tags={tagId}` 参数
- **并且** 博客页面应显示包含该标签的所有文章

#### 场景：标签链接格式正确
- **给定** 一个标签的 ID 为 "xyz-456"
- **当** 渲染该标签的链接
- **那么** 链接的 href 应为 `/blog?tags=xyz-456`
- **并且** 不应使用 name 作为参数值
- **并且** 参数名应为 `tags`（复数）而不是 `tag`（单数）
