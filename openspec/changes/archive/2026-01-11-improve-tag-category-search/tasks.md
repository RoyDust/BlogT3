# 任务列表：完善标签和分类的文章搜索功能

## 变更 ID
`improve-tag-category-search`

## 任务概述
本变更旨在修复侧边栏的标签和分类搜索功能，确保用户点击侧边栏的分类和标签时能够正确筛选文章。

---

## 任务列表

### 1. 更新侧边栏组件使用真实数据
**优先级**: 高
**预计工作量**: 中等
**依赖**: 无

**描述**:
- 将 `Sidebar.tsx` 从客户端组件改为服务器组件（移除 `'use client'`）
- 导入 `getCategories()`、`getTags()` 和 `getPosts()` 函数
- 获取真实的分类和标签数据
- 动态计算每个分类的文章数量
- 移除硬编码的 Mock 数据

**验证**:

- [x] 页面能够正常渲染，无错误

**文件**:
- `src/components/layout/Sidebar.tsx`

## 注意事项
1. **向后兼容**: 使用 `id || slug` 确保旧数据仍能工作
2. **性能考虑**: 侧边栏改为服务器组件后会在每次页面加载时查询数据库，但数据量小且可缓存
3. **测试数据**: 确保数据库中有足够的测试数据（分类、标签、文章）
4. **错误处理**: 确保在数据获取失败时有合理的降级处理
