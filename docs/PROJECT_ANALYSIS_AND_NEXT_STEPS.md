## 项目概述

BlogT3 是一个基于 Next.js 14 和 T3 Stack 构建的现代化博客系统，包含博客文章管理、摄影作品集、用户互动等功能。

### 技术栈
- **前端框架**: Next.js 14 (App Router)
- **数据库**: PostgreSQL
- **ORM**: Prisma (已完全迁移，不再使用 Supabase SDK)
- **认证**: NextAuth.js
- **样式**: Tailwind CSS
- **UI 组件**: Sonner (Toast 通知)
- **富文本编辑器**: TipTap
- **图片存储**: 七牛云 (Qiniu Cloud)

### 数据库模型
项目包含以下核心数据模型:
- **用户系统**: User, Account, Session, VerificationToken
- **博客系统**: Post, Category, Tag, Comment, PostTag
- **摄影系统**: PhotoGallery, PhotoImage, GalleryTag
- **互动系统**: Like, PostView, Feedback

## 安全性建议

> **注意：** 当前项目为个人博客，仅作者一人使用，不需要复杂的权限控制系统。

### 1. SQL 注入风险 ✅ 已解决

**已解决:**
- ✅ 已统一使用 Prisma ORM 进行数据库操作
- ✅ Prisma 自动提供参数化查询和 SQL 注入防护
- ✅ 所有查询都是类型安全的

**建议:**
- 继续使用 Prisma 进行所有数据库操作
- 避免使用原始 SQL 查询（除非必要）

### 2. XSS 攻击风险 🟡 中危

**问题:**
- 富文本内容可能包含恶意脚本
- 用户输入未经过滤

**建议:**
- 使用 DOMPurify 清理 HTML 内容
- 对用户输入进行转义
- 设置 Content Security Policy (CSP)

### 3. CSRF 攻击风险 🟡 中危

**问题:**
- Server Actions 可能缺少 CSRF 保护

**建议:**
- Next.js 14 的 Server Actions 默认有 CSRF 保护
- 确保所有表单使用 Server Actions
- 添加额外的验证令牌

### 4. 文件上传安全 🟡 中危

**问题:**
- 图片上传缺少文件类型验证
- 缺少文件大小限制
- 可能存在恶意文件上传风险

**建议:**
- 验证文件 MIME 类型
- 限制文件大小（如 10MB）
- 使用安全的文件存储服务
- 生成随机文件名，避免路径遍历

### 5. 敏感信息泄露 🟡 中危

**问题:**
- 错误信息可能暴露系统细节
- 日志可能包含敏感信息

**建议:**
- 生产环境使用通用错误信息
- 过滤日志中的敏感数据
- 使用环境变量管理密钥
- 定期审查代码中的硬编码凭证

### 6. 会话管理 🟢 低危

**问题:**
- 会话过期时间可能过长
- 缺少会话刷新机制

**建议:**
- 设置合理的会话过期时间
- 实现自动登出功能
- 添加"记住我"选项
- 支持多设备登录管理
